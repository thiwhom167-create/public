# เริ่มหารายได้กับโพสต์ปัง Studio

เว็บไซต์: https://postpang-studio.onrender.com  
ซอร์สโค้ด: https://github.com/thiwhom167-create/public  
หน้าเว็บเผยแพร่จาก branch `postpang-ai-launch` และโฟลเดอร์ `postpang-ai-site`

## สถานะจริงตอนนี้

- หน้าเว็บออนไลน์และเปิดให้คนทดลองเครื่องมือได้
- เครื่องมือแคปชั่นและแผนคอนเทนต์ใช้เป็นตัวอย่าง/เทมเพลตได้
- AI ออนไลน์ยังต้องตั้งค่า API key ฝั่งเซิร์ฟเวอร์ก่อน จึงจะยืนยันว่า AI ออนไลน์ทำงานจริงได้
- ต้องตั้งค่าช่องทางติดต่อธุรกิจที่เปิดเผยได้ (เช่น LINE link หรืออีเมลธุรกิจ) เพื่อให้ลูกค้าส่งคำขอถึงเจ้าของ
- ยังไม่มีระบบรับออเดอร์ เก็บข้อมูลลูกค้า หรือยืนยันการชำระเงินอัตโนมัติ
- ราคาบนหน้าเว็บเป็นข้อเสนอเริ่มต้น ต้องยืนยันขอบเขตงานและราคากับลูกค้าก่อนรับงานทุกครั้ง

## วิธีเริ่มขายโดยไม่ซื้อโฆษณา

1. เลือกกลุ่มเดียวก่อน เช่น คาเฟ่ ร้านขนม หรือร้านเสื้อผ้า
2. ดูหน้าเพจของร้านและจดสินค้า/เมนูจริง 1 อย่าง อย่าสร้างข้อมูลหรือคำกล่าวอ้างขึ้นเอง
3. สร้างตัวอย่างแคปชั่นให้ร้านนั้น 3 แบบ แล้วทักไปเสนอให้ทดลองดูโดยไม่กดดัน
4. ถ้าร้านสนใจ ให้ยืนยันจำนวนโพสต์ โทนภาษา วันส่ง และรอบแก้ไขเป็นข้อความก่อนเริ่มงาน
5. ส่งงานให้ตรงขอบเขต ขอความคิดเห็น และขออนุญาตก่อนนำคำรีวิวหรือผลงานลูกค้าไปโพสต์สาธารณะ
6. ติดต่อร้านทีละรายแบบสุภาพ ไม่ส่งสแปมจำนวนมาก และเคารพหากเขาไม่สนใจ

## ข้อความเริ่มคุยกับร้าน

สวัสดีครับ ผมกำลังเริ่มทำบริการช่วยร้านเล็ก ๆ คิดแคปชั่นและวางแผนคอนเทนต์ภาษาไทยครับ

ผมลองทำตัวอย่างให้ร้านดูได้ 3 แคปชั่นจากข้อมูลสินค้าหรือเมนูที่ร้านเผยแพร่ไว้ โดยไม่มีข้อผูกมัด หากชอบแนวทาง ค่อยเลือกแพ็กเกจที่เหมาะกับร้านได้ครับ

ขออนุญาตส่งตัวอย่างให้ดูไหมครับ?

## ตัวอย่างแพ็กเกจที่เว็บไซต์แสดง

- เริ่มต้น 590 บาท/รอบบริการ: 12 แคปชั่น, 4 ไอเดียคอนเทนต์, แก้ไข 1 รอบ
- ร้านโต 990 บาท/รอบบริการ: 20 แคปชั่น, 6 ไอเดียโปรโมชัน, ตารางคอนเทนต์ 7 วัน, แก้ไข 1 รอบ
- ร้านเด่น 1,490 บาท/รอบบริการ: 30 แคปชั่น, 8 ไอเดียโปรโมชัน, ตารางคอนเทนต์ 30 วัน, แก้ไข 2 รอบ

ราคาเป็นราคาเสนอเริ่มต้น ไม่ใช่หลักฐานว่าตลาดยอมจ่าย ควรทดสอบกับร้านจริงและตกลงขอบเขตงานก่อนรับเงิน ไม่รับประกันยอดขายหรือผลลัพธ์ของโพสต์

## คำนวณเป้าหมายรายรับ (ไม่ใช่กำไรสุทธิ)

- 11 รอบบริการ × 990 บาท = 10,890 บาทรายรับขั้นต้น
- 7 รอบบริการ × 1,490 บาท = 10,430 บาทรายรับขั้นต้น

รายรับจริงขึ้นอยู่กับจำนวนลูกค้า เวลาในการผลิตงาน ค่าใช้จ่าย และการซื้อซ้ำ จึงไม่มีการรับประกันว่าจะถึงเป้าหมายรายเดือน

## สิ่งที่ต้องตั้งค่าเพื่อให้รับลูกค้าได้จริง

- เพิ่ม LINE link หรืออีเมลธุรกิจที่เจ้าของอนุญาตให้เผยแพร่ลงใน `LINE_URL` หรือ `CONTACT_EMAIL` ในไฟล์ `postpang-ai-site/index.html`
- ทดสอบปุ่มสั่งบริการบนมือถือ และตรวจว่าปุ่มติดต่อเปิดไปยังช่องทางที่ถูกต้อง
- อย่าใส่ API key, รหัสผ่าน, ข้อมูลธนาคารส่วนตัว หรือข้อมูลลับลงใน repository สาธารณะ
- หากยังไม่บรรลุนิติภาวะ ให้ผู้ปกครองช่วยดูแลบัญชีรับเงิน เงื่อนไขการให้บริการ และภาระหน้าที่ที่เกี่ยวข้อง
- อย่าเปิดรับโอนเงินผ่านหมายเลขหรือชื่อผู้รับที่ยังไม่ได้ตรวจสอบ และอย่าโอนเงินให้ใครเพื่อแลกกับการได้ลูกค้าหรือการการันตีรายได้
