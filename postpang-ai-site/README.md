# โพสต์ปัง Studio

เว็บไซต์แคปชั่นภาษาไทยสำหรับร้านค้าขนาดเล็ก พร้อมหน้าแพ็กเกจบริการคอนเทนต์รายเดือน

## สิ่งที่ทำงานในเวอร์ชันนี้
- Responsive layout รองรับมือถือและคอมพิวเตอร์
- ตัวสร้างไอเดียแคปชั่น 3 แบบจากเทมเพลตในเบราว์เซอร์
- คัดลอกแต่ละข้อความหรือคัดลอกทั้งหมด
- แพ็กเกจบริการตัวอย่าง 590 / 990 / 1,490 บาท
- ปุ่มสนใจแพ็กเกจสร้างข้อความเริ่มต้นให้คัดลอกได้

## ข้อจำกัดที่ต้องรู้ก่อนโปรโมต
- ตัวสร้างในรุ่นนี้เป็นเทมเพลต JavaScript ไม่ได้เรียกโมเดล AI จริงหรือ API ภายนอก
- ไม่มีระบบสมาชิก ฐานข้อมูล ชำระเงิน หรือจัดการคำสั่งซื้อออนไลน์
- ตั้งค่า `LINE_URL` ใน `index.html` เป็นลิงก์ LINE ของผู้ให้บริการก่อนเปิดรับลูกค้าจริง หากยังไม่ตั้งค่า ปุ่มจะคัดลอกข้อความได้แต่ไม่เปิดแชตเจ้าของเว็บ
- ราคาเป็นตัวอย่าง ต้องยืนยันขอบเขตบริการ วันส่ง และรอบแก้ก่อนรับเงิน
- ไม่มีการรับประกันว่าจะทำรายได้ 10,000 บาทต่อเดือน

## เผยแพร่บน Render Static Site
- Repository: `https://github.com/thiwhom167-create/public`
- Branch: `postpang-ai-launch`
- Publish path: `postpang-ai-site`
- Build command: เว้นว่างหรือใช้ `echo static site`
- ชื่อบริการที่แนะนำ: `postpang-studio`

หลัง deploy แล้ว Render จะสร้าง URL สาธารณะของเว็บไซต์ให้ ควรเปิด URL จริงทดสอบบนมือถือและตรวจปุ่มทุกปุ่มก่อนแชร์กับลูกค้า

## แผนต่อยอด
1. ตั้งค่าช่องทางติดต่อจริง
2. สอบถามร้านค้า 10-20 ร้านเพื่อทดสอบว่าต้องการบริการอะไร
3. ขายบริการคอนเทนต์ด้วยตนเองก่อน เพื่อเรียนรู้ความต้องการและสร้างรายได้ก้อนแรก
4. เมื่อมีลูกค้าและความต้องการชัดเจน ค่อยเพิ่ม AI API ผ่าน backend ที่เก็บ secret อย่างปลอดภัย และตั้งค่าเพดานการใช้เพื่อควบคุมค่าใช้จ่าย
